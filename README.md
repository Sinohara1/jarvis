# Джарвис (Jarvis)

Личный голосовой ИИ-ассистент для Windows 10/11 с открытым кодом (Python, pywebview).
*Open-source personal voice assistant for Windows 10/11 (Python). UI and docs are in Russian; MIT license.*

Зовёшь по имени — отвечает голосом, открывает программы и сайты, управляет ПК, ищет файлы, ставит напоминания,
смотрит на экран и следит, чтобы ты не залипал в TikTok и шортсы во время фокус-сессий.

## Возможности
- **Вызов голосом по имени** («Джарвис, открой телеграм»), «Hey Jarvis» или горячая клавиша Ctrl+Alt+J — офлайн.
- **Голос**: локальный Piper TTS (быстро, без интернета) или Microsoft Edge TTS; несколько языков (ru/uk/en/de/pl).
- **Распознавание речи**: Vosk (офлайн, лёгкий) или Whisper (faster-whisper, точнее, на видеокарте NVIDIA или процессоре).
- **Модели ИИ**: Google Gemini, OpenAI, xAI Grok, Hubris, любой свой OpenAI-совместимый API (OpenRouter, LM Studio…),
  локально через Ollama (с запасным облачным провайдером).
- **Управление ПК** по уровням: выкл / стандарт / полный (окна, ввод текста, горячие клавиши, Telegram Desktop, shell, admin-скрипты).
- **Живой режим**: сам смотрит на экран и подсказывает, когда есть повод.
- **Страж фокуса**: помодоро-сессии и возврат из TikTok/Shorts/Reels.
- **Разговор без имени**: можно продолжать диалог после ответа (30 с / 2 мин / 10 мин / всегда).
- **Слышит звук ПК** (WASAPI loopback): знает, что сейчас говорят в видео/звонке — только как контекст, локально.
- **Память компаньона**, имя и характер ассистента, портативный режим, менеджер версий (обновление/откат).
- **Телефон как пульт** — только в локальной сети (LAN), см. ниже.

## Как скачать
1. Открой страницу **[Releases](https://github.com/Sinohara1/jarvis/releases)** и скачай `Jarvis.exe`
   из последней версии. Прямая ссылка на последнюю версию:
   https://github.com/Sinohara1/jarvis/releases/latest/download/Jarvis.exe
2. Положи `Jarvis.exe` в любую папку (например, на Рабочий стол) и запусти.
   Windows SmartScreen может предупредить о неизвестном издателе. Нажми «Подробнее» → «Выполнить в любом случае».
3. Если окно не открывается, установи [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
   (на Windows 11 он обычно уже есть).

## Где хранятся данные
Всё хранится только на твоём ПК: `%LOCALAPPDATA%\Jarvis` (настройки и ключи API в `settings.json`, память, чаты,
журнал, скачанные модели Vosk/Piper/Whisper, свои голоса). В портативном режиме — в папке `data` рядом с exe.
В репозитории нет и не должно быть пользовательских данных и ключей.

## Телефон
Это не отдельный Джарвис. Телефон открывает страницу с компьютера, в той же Wi‑Fi.
Ключи остаются на ПК, телефон только пишет в чат.

1. Запусти Джарвис на компьютере.
2. Вкладка **Настройки** → **Телефон**: адрес вида `http://192.168.x.x:8787` и PIN.
3. На телефоне открой этот адрес в браузере и добавь на домашний экран.
4. Введи PIN. Чат идёт через компьютер (можно попросить озвучить ответ на ПК).

> ⚠️ **Только локальная сеть.** Никогда не открывай порт 8787 в интернет (проброс портов на роутере, туннели вроде
> ngrok/Cloudflare Tunnel, VPS-прокси): через него управляется твой компьютер. PIN — не защита от интернета.

С версии 1.6 аддонов больше нет (Таверна, Финансы, Заметки и т.д. удалены). Их данные при обновлении
сохраняются архивом `%LOCALAPPDATA%\Jarvis\addons_backup_<дата>.zip`.

## Бесплатный ключ Gemini
Джарвису нужен ключ ИИ. Проще всего взять бесплатный ключ Google Gemini:
1. Зайди на https://aistudio.google.com/apikey под Google-аккаунтом.
2. Нажми **Create API key** и скопируй ключ.
3. В Джарвисе открой вкладку **«Модель»**, вставь ключ и нажми «Проверить».

Ключ хранится только у тебя на компьютере (`%LOCALAPPDATA%\Jarvis\settings.json`) и никуда больше не отправляется.

## Hubris и свой OpenAI-совместимый API (с версии 1.6)
Вкладка **«Модель»** → провайдер **«Hubris (рубли, все модели)»**: один ключ с оплатой в рублях даёт Gemini, GPT,
Claude, DeepSeek, Qwen, Grok и бесплатные модели.
1. Возьми ключ на https://hubris.pw/keys (вид `sk-gw-…`) и вставь его в поле ключа.
2. Модель — свободное поле: можно выбрать из подсказок или нажать **«Обновить список моделей»** (подгрузит все модели
   с ценами в ₽ за 1M токенов; модели с инструментами — вверху). Для голоса и команд нужна модель с инструментами.
3. По умолчанию: основная `google/gemini-3.8-flash`, лёгкая `google/gemini-3.1-flash-lite` (видит экран, вызывает команды).
   Бесплатно: `google/gemma-4-31b-it:free`, `hubris/free`.
- Мало денег на балансе — Джарвис так и скажет («Мало денег на балансе Hubris…»); неверный ключ, лимит ключа
  и неизвестная модель тоже объясняются по-русски.
- Режим «Сначала локально» работает и с Hubris: если локальная модель не справилась, ответит Hubris.

Провайдер **«Свой OpenAI-совместимый API»**: впиши адрес (`https://openrouter.ai/api/v1`, `http://127.0.0.1:1234/v1`
для LM Studio и т.п.), ключ и модель. Работают потоковые ответы, команды (tool calling) и снимки экрана, если модель
их поддерживает. Ключи хранятся только на этом ПК и не пишутся в лог.

## Имя и характер (с версии 1.1)
Во вкладке **«ИИ»** можно переименовать ассистента (имя появится в окне, трее, чате и ответах) и выбрать характер:
Джарвис-дворецкий, Друг, Строгий тренер, Саркастичный, Спокойный — или описать свой. Напоминания стража фокуса
тоже звучат в этом характере. С версии 1.2 ассистента можно звать голосом по этому имени.

## Память компаньона (настраиваемая)
Ассистент помнит между разговорами факты о тебе: кто ты, что любишь, близких людей, текущие проекты.
- Голосом или текстом: «запомни, что я люблю кофе без сахара», «забудь, что я учусь в 10 классе»,
  «что ты обо мне знаешь?». «Запомни, что …» сохраняется сразу, даже без модели.
- **ИИ → Память**: включить/выключить память; «Запомни, что …» — сохранять сразу; «Сам замечать важное в разговоре»
  (по умолчанию выкл: раз в несколько реплик модель выбирает устойчивые факты, это пара лишних запросов);
  сколько фактов хранить (25–500, старые незакреплённые вытесняются); сколько подмешивать в каждый ответ
  (0 — только когда спросишь); список фактов по категориям (о тебе, предпочтения, люди, проекты, разное) с закреплением
  и удалением; ручное добавление; кнопка «Очистить память».
- В каждый ответ уходит лишь несколько подходящих по теме фактов (до ~700 символов) — к выбранной модели, локальной или облачной.
- Хранится только на этом ПК: `%LOCALAPPDATA%\Jarvis\memory.json` (можно править руками; битый файл откладывается в `memory.json.bad`).
- Пароли, коды, ключи, токены, номера карт и IBAN не запоминаются; тексты фактов не пишутся в лог.

## Живой режим (с версии 1.2)
Ассистент сам время от времени смотрит на экран и решает, стоит ли сейчас что-то сказать: подсказать про ошибку
в коде, спросить, не нужна ли помощь, вернуть из ленты TikTok или похвалить. По умолчанию он молчит.
- Включить: переключатель **«Живой режим»** на главной или во вкладке **«ИИ»**, или голосом/текстом: «следи и подсказывай»,
  «включи живой режим». Выключить: «тихо», «хватит», «выключи живой режим».
- Настройки (вкладка «ИИ»): разговорчивость (редко / иногда / часто), как часто смотреть (по умолчанию каждые 45 с),
  пауза между репликами (3 мин), сколько слушать ответ после вопроса (8 с).
- Молчит, пока ты с ним говоришь, во время звонков и полноэкранных игр/видео и первые 20 с после смены окна.
  Во время фокус-сессии про отвлечения напоминает страж фокуса, двойных замечаний нет. При лимите бесплатного API смотрит реже.
- Снимок экрана уменьшается, отправляется только в модель и никогда не сохраняется на диск.

## Вызов по имени (с версии 1.2)
Вкладка **«Голос» → «Слово-активатор»**: «По имени» / «Hey Jarvis» / «Выкл». В режиме «по имени» скажи имя ассистента
(«Пятница», «Джарвис» — любое из вкладки «ИИ») или «Эй, Пятница», можно сразу с просьбой: «Пятница, открой телеграм».
Распознавание офлайн (Vosk); при первом включении один раз скачивается модель (~45 МБ) в `%LOCALAPPDATA%\Jarvis\models`.
Новое имя подхватывается сразу, без перезапуска.

## Разговор без имени и звук ПК (с версии 1.6)
Вкладка **«Голос» → «Разговор без имени»**.
- **Слушать после ответа**: выкл / 30 с / 2 мин (по умолчанию) / 10 мин / всегда. После голосового ответа или действия
  можно продолжать без имени: «а завтра?», «открой ещё ютуб». Таймер начинается заново после каждого ответа; на главной
  видно «слушаю… ещё 1:40» (нажми, чтобы закончить). «Хватит», «пока», «стоп слушать», «это всё» — конец разговора
  (если включён живой режим, «хватит» выключает и его).
- Пока ассистент говорит (и полсекунды после), микрофон не слушается — он не отвечает сам себе. Междометия, обрывки,
  неуверенно распознанное и одиночные шумы отсеиваются. Если фраза явно не ему (говоришь с кем-то, звук видео),
  модель может промолчать — в чате ничего не появится.
- **Всегда**: имя не нужно вообще, фильтры строже, при сомнении ассистент молчит. Лучше всего в наушниках;
  с колонками включи «Слышать звук ПК» — тогда фразы, которые просто повторяют звук из колонок, отбрасываются.
- Распознаёт Whisper, если он включён, иначе Vosk (офлайн); без локальных моделей в режимах с таймером — Gemini.
- **Слышать звук ПК** (по умолчанию выкл): звук колонок/наушников (видео, игры, звонки) захватывается через WASAPI loopback,
  речь распознаётся на этом ПК и последние ~3 минуты (текст, время, окно) подмешиваются в контекст как
  «что сейчас звучит на ПК». Можно спросить «что он сейчас сказал?», живой режим тоже это учитывает.
  Это только контекст: команды из колонок не выполняются. Пока ассистент говорит, звук ПК не слушается.
  Звук никуда не отправляется и не сохраняется — в модель уходит только текст. Whisper для звука ПК работает только на
  видеокарте NVIDIA и не во время игр (если включено «освобождать видеокарту в играх») — иначе Vosk на процессоре.
  Музыку и неразборчивую речь распознаёт плохо; при непрерывной речи часть фрагментов пропускается, чтобы не грузить ПК.

## Быстрый голос (с версии 1.3)
От конца фразы до первого звука теперь ~1,5 с вместо 11–15 с (если API Gemini отвечает нормально).
- **Голос на компьютере (Piper)**: вкладка **«Голос» → «Синтез речи»**: «Локальный (быстрый)» (по умолчанию) или
  «Microsoft Edge (онлайн)». Русские голоса: Дмитрий, Денис, Ирина, Руслан. Голос скачивается один раз (~60 МБ)
  в `%LOCALAPPDATA%\Jarvis\models\piper`, дальше работает без интернета. Если локальный голос недоступен, говорит Edge, и наоборот.
- **Распознавание речи на компьютере (Vosk)**: текст готов сразу, как ты замолчал; в Gemini уходит только текст.
  Если Vosk не уверен, запись уходит в Gemini как раньше. Вкладка «Голос» → «Скорость ответа» → «Распознавание речи»: «На компьютере» / «Gemini».
- **Конец фразы**: определяется нейросетевым VAD (Silero), пауза по умолчанию 0,6 с (ползунок «Пауза в конце фразы»).
- **Потоковый ответ**: ассистент начинает говорить первое предложение, пока модель пишет остальное. Ctrl+Alt+J или новая фраза перебивает.
- **«Быстрые ответы»**: голосовые вопросы идут в lite-модель (быстрее, отдельный лимит), набранные текстом — в основную.
- В той же карточке показано, сколько занял последний голосовой ответ (распознавание / модель / голос).

## Языки и свои голоса (с версии 1.4)
- **Язык ответов** (вкладка «Голос» → «Язык»): Русский, Українська, English, Deutsch, Polski или «Как я спросил» —
  отвечает на языке твоей последней фразы. Действует везде: чат, голос, живой режим, страж фокуса, напоминания,
  короткие фразы вроде «Открываю.». Интерфейс остаётся русским.
- **Голос под язык**: для каждого языка свой голос Piper (uk — Микита/Лада/Тетяна, en — Ryan/Lessac/Amy/Alan,
  de — Thorsten/Kerstin/Ramona, pl — Darkman/Gosia/MC Speech). Недостающий голос скачивается сам при первом ответе
  на этом языке (~60 МБ, в `%LOCALAPPDATA%\Jarvis\models\piper`), пока качается — звучит Microsoft Edge
  с голосом того же языка.
- **Язык, на котором я говорю** — отдельная настройка (по умолчанию русский). Для других языков офлайн-модель
  Vosk (40–80 МБ) скачивается при первом использовании; пока её нет — распознаёт Gemini.
- **Английские команды голосом** (`stt_commands.py`): шаблоны «write <кому> on Telegram, <текст>» и
  «play <трек> on Spotify» чинятся после распознавания — «right next door on telegram fellow i'm jarvis» →
  «Write Nehto on Telegram, hello I'm Jarvis». Если язык речи русский, а русская модель явно услышала английскую
  фразу, та же запись перепроверяется английской моделью Vosk (~41 МБ, скачивается сама при первой такой фразе;
  настройка «Английские команды»). Имя контакта модель угадать не может — впиши контакты в «Имена контактов для
  голоса», и похожее на слух («next door», «нехто», «nato») подставится как «Nehto».
- **Загрузить свой голос**: кнопка в «Свои голоса» → выбери `.onnx` голоса Piper (файл `.onnx.json` найдётся рядом,
  иначе спросит) или `.zip` с обоими. Голос проверяется (загрузка + тестовая фраза) и копируется в
  `%LOCALAPPDATA%\Jarvis\voices\<имя>\`; язык берётся из `.onnx.json`, и голос включается для этого языка.
  Где взять: https://huggingface.co/rhasspy/piper-voices, примеры: https://rhasspy.github.io/piper-samples/
- Лицензии: часть голосов (en Ryan, ru Руслан — CC BY-NC-SA; en Lessac — некоммерческая) только для личного использования.

## Локальная модель (с версии 1.5)
Ассистент может думать прямо на твоей видеокарте через [Ollama](https://ollama.com): без лимитов, без интернета,
скриншоты никуда не уходят. Вкладка **«Модель»**:
- **«Где думает ассистент»**: «Локально, Gemini запасной» (по умолчанию, если Ollama установлена), «Только локально»,
  «Только Gemini». В режиме «запасной» Gemini отвечает, если локальная модель не запущена, ещё грузится в видеопамять,
  отдана игре, ошиблась или не ответила вовремя. Разговор при этом не теряется.
- **Локальная модель**: список скачанных моделей, «Скачать модель» с прогрессом, состояние (готова / на видеокарте /
  сколько видеопамяти / когда выгрузится), «Выгрузить», «Проверить».
  По умолчанию **Gemma 4 12B** (`gemma4:12b`, ~8 ГБ на диске, ~9 ГБ видеопамяти): лучше всех по-русски
  и по-украински, видит экран, вызывает команды — безопасный баланс для live/фокуса на 16 ГБ.
  На RTX 5070 Ti 16 ГБ можно взять сильнее: **GPT-OSS 20B** (рассуждения/команды, без зрения экрана),
  **Gemma 4 26B** (умнее 12B + экран, впритык к 16 ГБ), **Qwen 3 14B** / **Qwen 3.5 27B**.
  Запасной лёгкий: Ministral 3 14B, Qwen 3.5 9B.
- **Живой режим и страж фокуса** тоже смотрят на экран локальной моделью, так что лимиты Gemini не тратятся.
- **«Освобождать видеопамять в играх»** (включено): когда на переднем плане игра (папки Steam/Epic/Riot…,
  полноэкранные программы) или тяжёлая программа для видеокарты (Premiere, After Effects, Blender, DaVinci…),
  модель выгружается из видеопамяти и отвечает Gemini. После игры модель загружается снова.
- **«Держать в видеопамяти»**: через сколько минут простоя выгрузить модель (по умолчанию 10).
- Ollama Джарвис запускает сам, без окна. Её значок в трее не нужен (автозапуск Ollama можно выключить).
- Распознавание речи и голос остаются как были (Vosk/Piper на компьютере, Gemini для сложных случаев).

## Точное распознавание речи: Whisper (необязательно)
**Голос → «Распознавание речи (офлайн)»** — выбор движка:
- **Vosk (лёгкий, сразу)** — как раньше: маленькая модель (~45 МБ), текст готов сразу, почти не грузит ПК, но путает
  короткие команды, имена и английские слова. Для проверки английских команд можно выбрать
  **«Английская модель Vosk: Точная (~128 МБ)»** (`vosk-model-en-us-0.22-lgraph`) вместо маленькой.
- **Whisper (точнее, нужна загрузка)** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper): распознаёт
  фразу целиком после паузы; русский, украинский, английский и смешанные фразы («открой Spotify и включи lo-fi»)
  выходят нормальными словами, английское — латиницей. Модели: Small (0,5 ГБ, можно без видеокарты),
  Medium (1,5 ГБ), **Large-v3 Turbo** (1,6 ГБ, рекомендую для RTX). «Где считать»: Авто / Видеокарта NVIDIA / Процессор.
  «Языки фразы»: «Мой язык + английский» (по умолчанию: язык определяется для каждой фразы, но только из этих двух) /
  «Только мой язык» / «Любой».
- Кнопка **«Скачать»** загружает модель (и ~550 МБ библиотеки cuBLAS от NVIDIA для видеокарты) один раз в
  `%LOCALAPPDATA%\Jarvis\whisper\` с проверкой контрольной суммы. Удалить — кнопкой «Удалить».
- Имя-активатор и потоковое распознавание по-прежнему делает Vosk; его текст — запасной, если Whisper не уверен
  или ещё не загрузился. После Whisper текст всё так же проходит исправления имён/команд и список «Имена контактов».

Честные ограничения Whisper:
- Он есть только в сборке, где установлен `faster-whisper` (exe больше на ~60–100 МБ и чуть дольше стартует);
  иначе в настройках написано «не входит в эту сборку».
- RTX 50xx (Blackwell): готовые ядра CTranslate2 собраны до sm_86, поэтому **первая** загрузка на видеокарту может идти
  несколько минут (драйвер компилирует ядра, потом берёт из кеша). INT8 на этих картах выключен — работает float16.
  Если видеокарта не запустилась, Whisper сам перейдёт на процессор (с Turbo это 2–8 с на фразу — выбери Small).
- Не потоковый: распознавание начинается после паузы (на RTX ~0,2–0,6 с на фразу).
- Пока включён, держит ~1,5–2 ГБ видеопамяти рядом с локальной моделью Ollama; в играх сам не выгружается —
  переключи на Vosk, чтобы освободить.
- На тишине/музыке Whisper иногда «придумывает» фразы («Продолжение следует…») — такие фильтруются, неуверенный
  результат уходит Vosk/Gemini.

## Telegram: как открывается чат и хрупкие места
«Открой чат с Мамой», «напиши Nehto привет», «открой избранное»: Джарвис выводит окно Telegram Desktop на передний план
(если оно в трее или закрыто — запускает Telegram.exe), затем:
- **Избранное / Saved Messages** → `Ctrl+0`;
- **@username** (или `t.me/...`, «собака nick») → ссылка `tg://resolve?domain=...` прямо в Telegram Desktop; если ссылка
  не открылась — поиск;
- **имя** → `Esc`, `Esc` (закрыть открытый чат/меню), `Ctrl+F` (поиск по чатам; `Ctrl+K` в Telegram — это «вставить ссылку»,
  не поиск), вставка имени через буфер обмена, пауза ~1,1 с (для латиницы ~1,8 с), `Enter` — открывается **первый** результат.
- В «Имена контактов для голоса» можно задать псевдоним: `Мама=@mama_tg`, `Сеня=Семён Петров`.

Хрупкие места (проверены только логикой и тестами, не на живом Telegram):
- `Enter` берёт первый результат поиска. Если первым оказался канал/группа с похожим именем — откроется он.
  Надёжнее @username или псевдоним.
- Имя должно быть как в Telegram и в именительном падеже. «С Мамой»/«с Сергеем» приводится к «Мама»/«Сергей»,
  но сложные формы — нет.
- Результаты поиска приходят по сети: на медленном интернете пауза может оказаться короткой (`TG_TIMING` в `pc_power.py`).
- Если `Esc` не закрыл открытый чат (поле ввода с черновиком и т.п.), `Ctrl+F` может искать внутри чата.
- Windows может запретить вывести окно вперёд (foreground lock); тогда применяются обходы (AttachThreadInput, Alt,
  свернуть/развернуть). Если фокус всё равно не получен, клавиши не нажимаются и об этом пишется в ответе.
- Ссылки `tg://` должны быть привязаны к Telegram Desktop (а не к браузеру/Microsoft Store-версии с другим обработчиком).
- Буфер обмена перезаписывается (имя чата / текст сообщения).
- Клавиши посылаются со скан-кодами, чтобы `Ctrl+F` работал и в русской раскладке, но форки (AyuGram, Kotatogram)
  и Telegram из Microsoft Store не проверялись.
- Сообщение вставляется к существующему черновику (без `Ctrl+A`) и отправляется `Enter`.

## Управление
- **Ctrl+Alt+J**: удерживай и говори; короткое нажатие — слушать до паузы; ещё раз — стоп.
- Слово-активатор (по имени или «**Hey Jarvis**», работает офлайн) включается во вкладке «Голос».
- Можно просто писать в поле ввода на главной.
- Крестик сворачивает в трей. Там же есть «Выход».

## Портативный режим (с версии 1.5.2)
Положи рядом с `Jarvis.exe` файл `portable.txt` — и все данные (настройки, ключи, память, чаты, скачанные
модели Vosk/Piper/Whisper, свои голоса, журнал) будут храниться в папке `data` рядом с exe,
а не в `%LOCALAPPDATA%\Jarvis`. Так можно держать отдельную «чистую» копию. Удалишь `portable.txt` — Jarvis снова
берёт данные из `%LOCALAPPDATA%\Jarvis`. Модели Ollama общие для всего ПК (они хранятся в самой Ollama).
Две копии одновременно не работают: вторая просто покажет окно первой (общая проверка «уже запущен»).

## Версии
**Настройки → «Версии»**: список всех версий с GitHub. Можно обновиться на новую или откатиться на старую
и потом вернуться обратно. Настройки, ключ, история чата и статистика при этом сохраняются.

## Для разработчика
- Нужны Windows 10/11 и Python 3.11+ (рекомендуется 3.13).
- Запуск из исходников: `Jarvis.bat` (через `.venv`, зависимости в `requirements.txt`):
  `python -m venv .venv` → `.venv\Scripts\pip install -r requirements.txt` → `Jarvis.bat`.
- Сборка exe: `powershell -ExecutionPolicy Bypass -File .\build_exe.ps1` (`-Setup` создаёт `.venv` и ставит зависимости).
  Результат — `dist\Jarvis.exe`. Папки `.venv`, `build`, `dist`, `build_assets` и `*.exe` в git не коммитятся.
  Whisper входит в сборку, только если в `.venv` установлен `faster-whisper`.
- Публикация версии: `.\publish_release.ps1 -Version X.Y.Z -Notes "..."` (нужен `gh auth login`) — создаёт GitHub Release
  в этом репозитории с файлом `Jarvis.exe`; встроенный менеджер версий читает публичные релизы без токена.
- Тесты: `python -m pytest -q tests/test_*.py`; сравнение локальных моделей на ПК: `python tests/local_compare.py --models gemma4:12b,ministral-3:14b [--cloud]`; с настоящим ключом: `python tests/live_ai_test.py`, `python tests/live_mode_test.py [--wake <vosk-model> <wav-dir>]`. Вёрстка в браузере: `web/index.html?mock`.
- Проверка локальных промптов (имя + язык + open_app) без Ollama: `python tests/test_local_prompt.py`.

Локальный голос: [Piper](https://github.com/OHF-Voice/piper1-gpl) (GPL-3.0), голоса [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) (Дмитрий и Денис: CC0, Ирина: лицензия RHVoice, Руслан: CC BY-NC-SA 4.0). VAD: [Silero VAD](https://github.com/snakers4/silero-vad) (MIT).
Задержку голоса можно замерить: `python tests/voice_latency.py --wavs <папка с q*.wav и text.txt> --null-audio`.

Модель слова-активатора «Hey Jarvis» взята из [openWakeWord](https://github.com/dscripka/openWakeWord) (CC BY-NC-SA 4.0).
Шрифты Manrope и Urbanist распространяются по лицензии SIL OFL.
