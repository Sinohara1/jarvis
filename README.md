# Джарвис (Jarvis)

Личный голосовой ИИ-ассистент для Windows 10/11. Слушает по горячей клавише, отвечает голосом,
открывает программы и сайты, ищет файлы, ставит напоминания, смотрит на экран и следит, чтобы ты
не залипал в TikTok и шортсы во время фокус-сессий.

## Как скачать
1. Открой страницу **[Releases](https://github.com/Sinohara1/jarvis-releases/releases)** и скачай `Jarvis.exe`
   из последней версии. Прямая ссылка на последнюю версию:
   https://github.com/Sinohara1/jarvis-releases/releases/latest/download/Jarvis.exe
2. Положи `Jarvis.exe` в любую папку (например, на Рабочий стол) и запусти.
   Windows SmartScreen может предупредить о неизвестном издателе. Нажми «Подробнее» → «Выполнить в любом случае».
3. Если окно не открывается, установи [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
   (на Windows 11 он обычно уже есть).

## Бесплатный ключ Gemini
Джарвису нужен ключ ИИ. Проще всего взять бесплатный ключ Google Gemini:
1. Зайди на https://aistudio.google.com/apikey под Google-аккаунтом.
2. Нажми **Create API key** и скопируй ключ.
3. В Джарвисе открой вкладку **«Модель»**, вставь ключ и нажми «Проверить».

Ключ хранится только у тебя на компьютере (`%LOCALAPPDATA%\Jarvis\settings.json`) и никуда больше не отправляется.

## Имя и характер (с версии 1.1)
Во вкладке **«ИИ»** можно переименовать ассистента (имя появится в окне, трее, чате и ответах) и выбрать характер:
Джарвис-дворецкий, Друг, Строгий тренер, Саркастичный, Спокойный — или описать свой. Напоминания стража фокуса
тоже звучат в этом характере. С версии 1.2 ассистента можно звать голосом по этому имени.

## Живой режим (с версии 1.2)
Ассистент сам время от времени смотрит на экран и решает, стоит ли сейчас что-то сказать: подсказать про ошибку
в коде, спросить, не нужна ли помощь, вернуть из ленты TikTok или похвалить. По умолчанию он молчит.
- Включить: переключатель **«Живой режим»** на главной или во вкладке **«ИИ»**, или голосом/текстом: «следи и подсказывай»,
  «включи живой режим». Выключить: «тихо», «хватит», «выключи живой режим».
- Настройки (вкладка «ИИ»): разговорчивость (редко / иногда / часто), как часто смотреть (по умолчанию каждые 45 с),
  пауза между репликами (3 мин), сколько слушать ответ после вопроса (8 с).
- Молчит, пока ты с ним говоришь, во время звонков и полноэкранных игр/видео и первые 20 с после смены окна.
  Во время фокус-сессии про отвлечения напоминает страж фокуса, двойных замечаний нет. При лимите бесплатного API смотрит реже.
- Снимок экрана уменьшается, отправляется только в модель и никогда не сохраняется на диск.

## Вызов по имени (с версии 1.2)
Вкладка **«Голос» → «Слово-активатор»**: «По имени» / «Hey Jarvis» / «Выкл». В режиме «по имени» скажи имя ассистента
(«Пятница», «Джарвис» — любое из вкладки «ИИ») или «Эй, Пятница», можно сразу с просьбой: «Пятница, открой телеграм».
Распознавание офлайн (Vosk); при первом включении один раз скачивается модель (~45 МБ) в `%LOCALAPPDATA%\Jarvis\models`.
Новое имя подхватывается сразу, без перезапуска.

## Быстрый голос (с версии 1.3)
От конца фразы до первого звука теперь ~1,5 с вместо 11–15 с (если API Gemini отвечает нормально).
- **Голос на компьютере (Piper)**: вкладка **«Голос» → «Синтез речи»**: «Локальный (быстрый)» (по умолчанию) или
  «Microsoft Edge (онлайн)». Русские голоса: Дмитрий, Денис, Ирина, Руслан. Голос скачивается один раз (~60 МБ)
  в `%LOCALAPPDATA%\Jarvis\models\piper`, дальше работает без интернета. Если локальный голос недоступен, говорит Edge, и наоборот.
- **Распознавание речи на компьютере (Vosk)**: текст готов сразу, как ты замолчал; в Gemini уходит только текст.
  Если Vosk не уверен, запись уходит в Gemini как раньше. Вкладка «Голос» → «Скорость ответа» → «Распознавание речи»: «На компьютере» / «Gemini».
- **Конец фразы**: определяется нейросетевым VAD (Silero), пауза по умолчанию 0,6 с (ползунок «Пауза в конце фразы»).
- **Потоковый ответ**: ассистент начинает говорить первое предложение, пока модель пишет остальное. Ctrl+Alt+J или новая фраза перебивает.
- **«Быстрые ответы»**: голосовые вопросы идут в lite-модель (быстрее, отдельный лимит), набранные текстом — в основную.
- В той же карточке показано, сколько занял последний голосовой ответ (распознавание / модель / голос).

## Языки и свои голоса (с версии 1.4)
- **Язык ответов** (вкладка «Голос» → «Язык»): Русский, Українська, English, Deutsch, Polski или «Как я спросил» —
  отвечает на языке твоей последней фразы. Действует везде: чат, голос, живой режим, страж фокуса, напоминания,
  короткие фразы вроде «Открываю.». Интерфейс остаётся русским.
- **Голос под язык**: для каждого языка свой голос Piper (uk — Микита/Лада/Тетяна, en — Ryan/Lessac/Amy/Alan,
  de — Thorsten/Kerstin/Ramona, pl — Darkman/Gosia/MC Speech). Недостающий голос скачивается сам при первом ответе
  на этом языке (~60 МБ, в `%LOCALAPPDATA%\Jarvis\models\piper`), пока качается — звучит Microsoft Edge
  с голосом того же языка.
- **Язык, на котором я говорю** — отдельная настройка (по умолчанию русский). Для других языков офлайн-модель
  Vosk (40–80 МБ) скачивается при первом использовании; пока её нет — распознаёт Gemini.
- **Загрузить свой голос**: кнопка в «Свои голоса» → выбери `.onnx` голоса Piper (файл `.onnx.json` найдётся рядом,
  иначе спросит) или `.zip` с обоими. Голос проверяется (загрузка + тестовая фраза) и копируется в
  `%LOCALAPPDATA%\Jarvis\voices\<имя>\`; язык берётся из `.onnx.json`, и голос включается для этого языка.
  Где взять: https://huggingface.co/rhasspy/piper-voices, примеры: https://rhasspy.github.io/piper-samples/
- Лицензии: часть голосов (en Ryan, ru Руслан — CC BY-NC-SA; en Lessac — некоммерческая) только для личного использования.

## Управление
- **Ctrl+Alt+J**: удерживай и говори; короткое нажатие — слушать до паузы; ещё раз — стоп.
- Слово-активатор (по имени или «**Hey Jarvis**», работает офлайн) включается во вкладке «Голос».
- Можно просто писать в поле ввода на главной.
- Крестик сворачивает в трей. Там же есть «Выход».

## Версии
**Настройки → «Версии»**: список всех версий с GitHub. Можно обновиться на новую или откатиться на старую
и потом вернуться обратно. Настройки, ключ, история чата и статистика при этом сохраняются.

## Для разработчика
- Запуск из исходников: `Jarvis.bat` (через `.venv`, зависимости в `requirements.txt`).
- Сборка exe: `powershell -ExecutionPolicy Bypass -File .\build_exe.ps1` (`-Setup` переустанавливает зависимости).
- Публикация версии: `.\publish_release.ps1 -Version X.Y.Z -Notes "..."` (нужен `gh auth login`).
- Тесты: `python tests/test_logic.py`; с настоящим ключом: `python tests/live_ai_test.py`, `python tests/live_mode_test.py [--wake <vosk-model> <wav-dir>]`. Вёрстка в браузере: `web/index.html?mock`.

Локальный голос: [Piper](https://github.com/OHF-Voice/piper1-gpl) (GPL-3.0), голоса [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) (Дмитрий и Денис: CC0, Ирина: лицензия RHVoice, Руслан: CC BY-NC-SA 4.0). VAD: [Silero VAD](https://github.com/snakers4/silero-vad) (MIT).
Задержку голоса можно замерить: `python tests/voice_latency.py --wavs <папка с q*.wav и text.txt> --null-audio`.

Модель слова-активатора «Hey Jarvis» взята из [openWakeWord](https://github.com/dscripka/openWakeWord) (CC BY-NC-SA 4.0).
Шрифты Manrope и Urbanist распространяются по лицензии SIL OFL.
